# 시간대 4테마 색 토큰 설계

개인 블로그 `limjaejoon.com`의 기초 디자인 토큰을 세운다. 무드는 "감성 카페" — 하루의 시간대를 따라 분위기가 바뀐다. 현재 `src/shared/styles/theme.css.ts`는 일반적인 단일 테마(회색 + 파란 accent) 하나뿐이라 컨셉과 따로 논다. 이 설계는 같은 토큰 컨트랙트 위에 **오후·노을·밤·새벽 4테마**의 순수 색 값을 정의해, 컴포넌트는 토큰만 보고 테마 클래스 교체로 분위기를 갈아끼우게 한다. 이번 산출물은 **색 토큰뿐**이다.

## 1. 목표와 비목표

**목표**
- "감성 카페" 무드의 기초 색 토큰을 세운다.
- 시간대 4테마(오후/노을/밤/새벽)를 하나의 컨트랙트 위에 정의한다.
- 컴포넌트는 `vars.color.*`만 참조하고, 테마는 클래스 교체로만 바뀌게 한다.
- AI티(흔한 보라/파랑 그라데이션·글로우, 글래스 남발, 템플릿틱·디테일 클리셰)가 없는, 절제된 손맛.

**비목표**
- 그림자·hover·상태색(disabled 등)·글래스·그라데이션·모션 같은 **이펙트 토큰** — 사용자가 직접 만든다.
- 테마 전환 메커니즘(시간 따라 자동 / 수동 토글) — 별도 결정. 토큰엔 영향 없음.
- 공용 컴포넌트(Radix 래핑 등) 구현 — 후속 작업.
- 타입 스케일·간격 스케일 신설 — 간격은 기존 `sprinkles`가 담당, 타이포 스케일은 이번 범위 밖.

## 2. 컨셉

하루의 빛이 바뀌는 카페. 4테마는 시간 순서 — 오후(쩅하게 밝은 대낮) → 노을(저녁 6~7시) → 밤(10시 이후, 검은색에 가까움) → 새벽(남보라 트와일라잇). 같은 글·같은 구조 위에서 빛의 온도/밝기만 달라진다. accent는 흔한 테크블루/바이올렛을 버리고 각 시간대의 **자연광에서 뽑은 따뜻·절제 톤**으로 둔다.

## 3. 토큰 컨트랙트 (모양)

기존 `createThemeContract` 구조를 유지한다. 역할은 다음과 같다.

| 토큰 | 역할 | 테마별로 바뀜? |
|---|---|---|
| `color.background` | 페이지 바탕 | ✓ |
| `color.surface` | 카드·표면 | ✓ |
| `color.text` | 본문 글자 | ✓ |
| `color.muted` | 보조 글자(메타·캡션) | ✓ |
| `color.border` | 테두리·구분선 | ✓ |
| `color.accent` | 강조(링크·태그) — 시간대 자연광 | ✓ |
| `radius.sm` `radius.md` `radius.lg` | `0.25` / `0.5` / `0.75rem` | 공통 |
| `font.body` `font.mono` | 기존 값 유지 | 공통 |

## 4. 4테마 값

| | background | surface | text | muted | border | accent |
|---|---|---|---|---|---|---|
| **오후** `afternoon` | `#eef4fb` | `#ffffff` | `#1c2630` | `#5d6b7a` | `#d8e2ee` | `#c79338` (꿀빛 골드) |
| **노을** `sunset` | `#2c2030` | `#3a2b3c` | `#f6e7d6` | `#c2a18d` | `#4f3b49` | `#e07a45` (잉걸불) |
| **밤** `night` | `#0a0b10` | `#14161e` | `#e7eaf3` | `#8a93ac` | `#232838` | `#d8c39a` (달빛 아이보리) |
| **새벽** `dawn` | `#1b2038` | `#262b46` | `#e9eaf6` | `#a3a8cb` | `#353b59` | `#cf8f86` (옅은 장미) |

- `radius`, `font`은 4테마 공통(기존 값 유지).
- 오후는 라이트, 나머지 셋은 다크 계열. 밤(차가운 near-black)과 새벽(남보라)은 의도적으로 구분.

## 5. 구현 방향

- `createThemeContract`(컨트랙트 `vars`)는 그대로 두고, `createTheme`을 **1개 → 4개**로 확장한다: `afternoonThemeClass`, `sunsetThemeClass`, `nightThemeClass`, `dawnThemeClass`.
- 기존 `defaultThemeClass`를 `afternoonThemeClass`로 이름 바꾸고, 이를 기본 적용 테마로 둔다. **기본 테마 = 오후(라이트)** — 블로그 가독성 기준. 변경 가능.
- `global.css.ts`의 `:focus-visible` outline은 이미 `vars.color.accent`를 참조하므로 그대로 동작한다.
- 테마 클래스를 어디에 적용할지(html/body)와 전환 UI는 이 설계의 범위 밖(후속).

## 6. 명시적 비범위 — 이펙트

그림자·hover·상태색·글래스·그라데이션·모션은 **사용자가 직접** 만든다. 토큰 컨트랙트에 이 역할들을 추가하지 않는다. 색 토큰은 그 위에 효과를 얹을 단단한 바닥 역할만 한다.

## 7. 거주지 / 적용 범위

- `src/shared/styles/theme.css.ts` 갱신: 컨트랙트 유지 + 4개 테마 클래스 정의.
- 테마 적용·전환 배선(layout, 토글 등)은 별도 후속 작업.
- 린트/시각 회귀 강제는 이번 범위 밖.
