# assets

dessert99-blog is a **from-scratch brand** — there were no pre-existing logos, illustrations, or
photography to vendor. Its visual identity is intentionally **typographic + token-driven**:

- **Wordmark:** `dessert99` set in Pretendard SemiBold, lowercase, with `99` in
  `--md-sys-color-primary` (so it recolors per season). Rendered in CSS — see `preview/brand-mark.html`.
- **Avatar / favicon mark:** the digits **"99"** in a `full`/rounded primary container.
- **Icons:** Material Symbols Rounded, loaded as a CDN icon font (not stored here). See README §6.
- **Fonts:** Pretendard + D2Coding load from jsDelivr via `@font-face` in `../colors_and_type.css`.
  Roboto Mono + Material Symbols load from Google Fonts.

No raster assets are stored in this folder yet. **If you'd like a real logo, illustration set, or
seasonal hero imagery, send it over and it will be vendored here** and referenced from the kit.
